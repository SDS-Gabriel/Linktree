# Linktree

🧠 Conceitos Práticos Desenvolvidos
Durante a construção desta réplica, foram exercitados os seguintes tópicos de desenvolvimento front-end:

🛠️ Estrutura HTML5 Semântica
Identificação de Perfil: Uso de tags de imagem (<img>) e títulos (<h1> e <h2>) para a foto de perfil, nome e uma breve biografia.

Lista de Conexões: Utilização de uma lista não ordenada (<ul>) onde cada item (<li>) engloba um link (<a>), garantindo que a estrutura seja acessível para leitores de tela.

Rodapé Organizacional: Inclusão de uma tag <footer> para créditos do projeto ou ícones de redes sociais secundárias.

🎨 Estilização e Efeitos CSS3
Estilização de Botões: Criação de caixas personalizadas com bordas arredondadas (border-radius), espaçamentos internos (padding), sombras projetadas (box-shadow) e cores de fundo contrastantes.

Manipulação do Cursor e Hover: Mudança do cursor para o formato de clique (cursor: pointer) e alteração suave de cores ou tamanhos dos botões (transition) ao interagir com eles.

Fundo Personalizado: Aplicação de gradientes de cores (linear-gradient) ou imagens de fundo para simular os temas reais do Linktree.

Largura Máxima Controlada: Uso de propriedades como max-width e margin: 0 auto para garantir que a lista de links não estique infinitamente em telas grandes, mantendo o visual centralizado clássico de aplicativos móveis.
